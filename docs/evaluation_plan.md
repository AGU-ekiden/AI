# 研究評価の方法（2026-10-19 利用者承認「とりあえず進めて」）

目的：特徴量を増やしながら、**どの特徴量が箱根の成果（往路区間5位以内・復路区間2位以内）と強く結びつくか**を、
1つの評価値で測り続ける。個人の予測・確率・順位は出さない（集団での評価だけ）。

## 評価値
**世代順の検証での平均適合率（PR-AUC）**。0〜1で、高いほど「達成した人を上位にまとめて並べられる」特徴量の組み合わせ。
- 偶然の水準＝達成者の割合（約15%）。基準モデル＝**5000mベスト（高校観測期間）だけ**。
- **上積み**＝評価値 − 基準。これが「5000mベストでは分からない情報をどれだけ足せたか」。
- 上積みには95%区間（同じ人の組での再抽出）をつける。区間が0をまたぐ差は偶然の範囲。

## 手順（`labo/research_eval.py`）
1. 対象：入学年度が判明している人。成果ラベルが「達成」「未達成（確定）」の人だけを使う。**追跡中・不明は使わない**（0扱いしない）。
2. 世代順の検証：入学年度Yの人を評価するときは、**Yより前の世代だけで学習**（2010年度入学から評価、学習側の達成者15人以上の年度のみ）。
   全年度の結果を集めて評価値を出す。
3. モデル：L2付きロジスティック回帰（標準ライブラリで実装）。欠損は学習側の中央値で埋め、欠損の有無も入力にする。
   標準化・中央値は学習側のデータだけで決める。
4. **最終確認用の取り置き**：2018年度入学以降は日常の評価に使わない。特徴量を何度も試すと評価値がたまたま高い組み合わせを選びがちなので、
   ときどき `--final-check` で取り置き世代を含めて確かめる（履歴に「最終確認」と残る）。
5. 品質表示専用の特徴量（出走数・観測期間など、掲載量を反映するもの）はモデルに入れない。

## 出力（集計のみ・共有可）
- `data/eval_summary.json`：評価値・基準・上積みと区間、特徴量ごとの「基準に1つ足したときの上積み」「全体から1つ抜いたときの低下」、
  全開発世代での係数（1標準偏差あたり）、較正（5区間の平均予測と実際の割合・人数）、年度別人数。
- `data/eval_history.jsonl`：実行ごとの評価値の推移。
- 個人ごとのスコア・確率・順位は作成も保存もしない。

## セットの決め方（第1回の結果を受けて 2026-10-19）
- 評価値は **基準（5000mベスト）＋「研究で採用」にした特徴量** のセットで出す。最初はセット＝基準だけ。
- 候補の特徴量（計算可能なもの）は1つずつ「いまのセットに足したら評価値がどれだけ上がるか（95%区間つき）」を出す。
  区間が0より上なら「研究で採用」にしてセットに入れる → 次の実行で評価値が上がる、をくり返す。
- セット内の特徴量は「抜いたらどれだけ下がるか」も出す。下がらないものは外してよい。
- 第1回で、似た特徴量をまとめて入れると評価値が下がることを確認（5000m系11件で 0.401 → 0.349）。
- `--all` で全候補を入れたセット、`--features` で任意のセットも評価できる。

## 使う世代（2026-10-20 第3回の診断を受けて）
- **2011年度入学以降だけ**を学習・評価に使う。2010年度以前は5000mの記録がある人が3〜5割、伊那駅伝は0、県・地区駅伝も2007年度以前は0と、
  rkm の収録が薄い。古い世代の「記録なし」は掲載の薄さで、新しい世代の「記録なし」と意味が違うため、古い世代で学んだ関係が新しい世代に当てはまらない。
- 評価は2013年度入学から（学習側の達成者12人以上の年度）。2018年度以降の取り置きは従来どおり。
- 候補者の点数の学習も同じ世代に揃える。

## 回し方
```powershell
python scripts/run_evaluation.py                     # 基準＋「研究で採用」のセット。候補は1つずつ試す
python scripts/run_evaluation.py --features best_5000_s@1,grade1_to_grade2_improvement_s@1 --note "伸びだけ"
python scripts/run_evaluation.py --final-check       # たまにだけ
```
`data\eval_summary.json` を Claude に渡すと、スマホ用ダッシュボードに評価値と推移を出す。

## 注意
- 達成者は1世代あたり10人前後と少ない。0.01〜0.02程度の差は偶然で動く範囲。区間と「1つ足したときの上積み」をあわせて見る。
- 関係があることは、原因であることを意味しない（例：強豪校に多い特徴は、学校の影響かもしれない）。
- 箱根の記録欠け（2015・2016年など）が残る世代は「不明」が多く、評価に入る人数が減る。
