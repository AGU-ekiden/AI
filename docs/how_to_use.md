# 特徴量ラボの使い方（かんたん版）

## これは何をする道具か
高校の記録から「特徴量」（例：5000mベスト、中学3000mベスト、伊那駅伝の区間順位）を作り、
それを足すと箱根での活躍（往路区間5位以内・復路区間2位以内）を**集団として**どれだけ説明できるようになるかを
「評価値」で確かめる道具。評価値が上がる特徴量を見つけて、セットに足していく。個人の予測や順位は出さない。

## 初回だけ（これで以後は自動で最新版になる）
1. Git for Windows を入れる（https://git-scm.com/download/win。設定はすべて既定のままでよい）。
2. PowerShell で、置きたい場所に移動して取得（GitHub へのログインを1回求められる）：
   ```powershell
   cd $HOME\Documents
   git clone -b claude/new-session-pnnp13 https://github.com/AGU-ekiden/AI.git labo-ai
   ```
3. 前に使っていたフォルダの `data` フォルダを、新しい `labo-ai` フォルダの中へコピー（トークン・判断記録・集計が入っている）。
4. 接続文字列を**この PC の利用者の環境変数**に保存（チャットやファイルには書かない）：
   ```powershell
   [Environment]::SetEnvironmentVariable("RKM_READONLY_DSN", "（lab_reader の接続文字列）", "User")
   ```
以後は **`labo-ai` フォルダの `start_lab.bat` をダブルクリック**するだけ。最新版の取得 → 起動 → ブラウザが開く、まで自動。

## 毎回の流れ（ほぼ「研究状況」画面だけで完結）
1. **起動**（チームPCの PowerShell。リポジトリのフォルダで）
   ```powershell
   $env:RKM_READONLY_DSN = "（lab_reader の接続文字列）"
   $env:LABO_DATA_SOURCE = "rkm"
   python -m labo.server
   ```
   表示された `http://127.0.0.1:8765/` をブラウザで開く。
2. **ログイン**：初回は `data\.token` の中身（トークン）を貼る。
3. **研究状況**（最初に開く画面）を見る
   - 上：評価値と基準（5000mベストだけ）。評価値が基準より大きいほど、足した特徴量が役に立っている。
   - 下：特徴量ごとの一覧。「いまのセットに足す」の棒が**緑**＝足すと評価値がはっきり上がる。
4. **ボタンを押す**
   - 「テスト済み」の特徴量がある → 「まとめて計算可能にする」
   - 「実データで再計算・再評価」→ 数分待つ
   - 緑になった特徴量 → 「研究で採用」→ もう一度「再計算・再評価」→ 評価値が上がったか確認
   - 「自動選択の提案」に関門を通った特徴量が出ていれば、「研究で採用」を押すだけでもよい（設定で上限・基準・使わない特徴量を変えられる）
5. 新しい特徴量を思いついたら：**Claude に言う**（例：「春の高校伊那駅伝を入れたい」）か、「特徴量作成」画面で作る。

## ほかの画面（普段は使わなくてよい）
| 画面 | 使う場面 |
|---|---|
| 研究状況 | **普段はここだけ** |
| 候補者 | 一人ひとりの点数（範囲つき）・期待超え・根拠。結果待ちの世代／結果が出た世代（答え合わせ）を切り替え |
| ファクター一覧 | 特徴量の定義の詳細を見る・状態を1件ずつ変える |
| 特徴量作成 | 自分で特徴量を作る（許可された計算方法から選ぶ） |
| 計算実行・結果確認・実験履歴 | 個人ごとの値を見たいとき（手計算との突き合わせなど） |
| 品質・保留 | 使わなかった記録とその理由を確認する |
| 研究トップ | データの概要 |

## 用語
- **評価値（PR-AUC）**：0〜1。達成した人を上位にまとめて並べられるほど高い。偶然なら約0.16。
- **基準**：5000mベストだけで出した評価値（約0.40）。
- **上積み**：評価値 − 基準。
- **95%区間**：上積みのぶれの幅。0をまたぐなら偶然の範囲。
- **計算可能**：実データで計算してよいと承認した状態。**研究で採用**：評価値のセットに入れた状態。
